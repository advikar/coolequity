# Project documentation maintenance

When changing product features or data behavior, update `FEATURES.md` and `DATA_QUALITY.md`
in the same change. Keep current behavior distinct from historical audit notes. Update
`STATUS.md` for significant work. User-facing source/method explanations in `app/guide.html`
must agree with the implementation and the current datasets. Do not describe estimates or
planning assumptions as directly measured facts. Record which city branches were changed.
