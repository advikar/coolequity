Not a static map — an interactive tool. Six data layers, a redlining overlay, a cooling-access layer, a ranked priority list, and a per-block intervention calculator. It runs entirely on static files, so it works with no network at all.

The pipeline

Five steps, all reproducible.

01
Grid
H3 res-8 tessellation over the city bbox. Uber's hex index — equal-area, no census geography.
02
Satellite
Landsat 8/9 ST_B10 thermal → °C, and Sentinel-2 NDVI. Summer 2023 medians via Planetary Computer.
03
Census
ACS 2023 block groups — population, age 65+, income — area-weighted into hexes.
04
Overlays
HOLC grades by majority overlap; cooling sites via Overpass; walk time to nearest relief.
05
Score
Normalise, weight, rank. Writes the GeoJSON the front end reads.

Every source is open and every step is cached, so the whole thing rebuilds from a bounding box and an API key.

The score

Weighted, transparent, and normalised inside the city.

base_risk = 0.35·heat + 0.25·(1−canopy) + 0.25·(1−ac_access) + 0.15·age65
priority  = base_risk × (0.55 + 0.45 · population)
score    = 100 × minmax(priority)

Normalising within the city is what makes the engine portable. 44 °C is an ordinary afternoon in Phoenix and an emergency in Seattle — a globally fixed threshold would be wrong in both. Weights live in one config file, so when a judge or a city asks "why 35%?", the answer is editable in a line.

Where we corrected ourselves

The obvious next claim was wrong, so we dropped it.

We expected: redlined areas are also farther from relief.
The data says: they are closer — 12.2 minutes versus 20.3.

Dense inner-city neighbourhoods have libraries and community centres; leafy low-density suburbs don't. So in Los Angeles the redlining signal is heat and missing shade — not distance to relief.

It would have been an easier story to leave in. It also would have been false, and visible as false on our own access layer while we said it.

Validation

Shade is doing the work — not the coastline.

LA cools and greens toward the ocean, so a raw correlation could be pure geography. Splitting by longitude and removing a quadratic lon/lat trend both leave the relationship intact. We also dropped 478 uninhabited hexes — open ocean reads 18 °C with zero vegetation and would have inverted the headline result.

What's measured, what's modelled

Stated up front, and labelled in the interface.

Modelled

A/C access is derived from median income, not measured. It carries 25% of the score and is shown as est. in the UI — the weakest input we have.

Estimated

Walk time is straight-line distance × 1.273 — that's 4/π, the expected Manhattan-to-Euclidean ratio over uniform bearings — at 4.8 km/h. Correct for a grid city; not a routed street network.

Proxy

Canopy is NDVI 0.05–0.65 scaled to 0–45%. Vegetation cover, not strictly tree crown.

Measured

Surface temperature, population, age and cooling-site locations are observed data — Landsat thermal, ACS, OpenStreetMap.

Why it matters

Every input but one is global.

Landsat, Sentinel-2, OpenStreetMap and gridded population exist for every city on Earth. Only the redlining overlay is US-specific — and it's an optional layer, not an input to the score. Point the pipeline at a new bounding box and it answers the same question.
